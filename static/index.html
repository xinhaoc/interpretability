    interpretability

    读懂每一篇论文

    导入一篇论文。AI 会先通读全文写一份笔记，之后你读到哪里不懂，就选中那段文字、或者框选公式和图，让它解释。

    1. 选中文字 → 弹出按钮：解释 / 推导 / 通俗讲 / 联系全文 / 挑毛病，或者直接打字提问
    2. 按 R 或按住 Option 拖一个框 → 截图发给模型（适合公式、图、表）
    3. 每个问题是一个线程，可以继续追问；页面上的高亮可以点回去
    拖一个框选中公式 / 图 / 表 · Esc 取消
    推导图

    这篇论文是怎么一步步推出来的？

    生成一张可编辑的推导图：从问题出发，经过关键想法、方法里的每一步公式，到实验证据和局限。每个节点都标出原文出处，图表节点直接显示原图，引用的原文会自动核对。

    双击节点改字，Tab 加子节点，拖动调整结构，右键有更多操作。你改过的导图会存进这篇论文的记忆。
